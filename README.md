# QuantumScalper M1: EA สำหรับเทรดกราฟ 1 นาที (MetaTrader 5)

ไฟล์ EA: `MQL5/Experts/QuantumScalper_M1.mq5`

## คุณสมบัติหลัก

| ส่วน | การทำงาน |
|---|---|
| **สัญญาณเข้า (M1)** | ดูเทรนด์จาก EMA 9/21 บน M1, EMA 50 บน M15 (ต้องชันไปทางเดียวกัน) และ ADX/DI จากนั้นรอจังหวะย่อ คือ RSI(7) ตัดกลับขึ้นจาก 40 (ฝั่ง Sell คือตัดลงจาก 60) หรือแท่งเทียนแตะ EMA เร็วแล้วเด้งกลับ ถ้าแท่งไหนยาวเกิน 2.5 ATR จะไม่เข้า |
| **TP / SL เสมอ** | ทุกออเดอร์ส่ง SL และ TP ไปพร้อมคำสั่งเปิด ถ้าพบออเดอร์ที่ไม่มี SL/TP (เช่นมีการลบด้วยมือ) EA จะใส่ให้ใหม่ทันที ตอนเลื่อน SL/TP จะไม่ยอมให้ค่าเป็น 0 |
| **TP1 / TP2 / TP3** | แบ่งล็อตเป็น 3 ไม้ (ค่าเริ่มต้น 40% / 30% / 30%) ปิดที่ TP1 = 1 ATR, TP2 = 2 ATR, TP3 = 3.5 ATR |
| **กันทุน / ล็อกกำไร** | เมื่อถึง TP1 จะเลื่อน SL ไปที่ทุน (+20 จุด) เมื่อถึง TP2 จะเลื่อน SL ไปล็อกกำไรไว้ที่ระดับ TP1 |
| **ปล่อยกำไรไหล (Trend Runner)** | หลังผ่าน TP2 ถ้าเทรนด์ยังแรง (ADX ≥ 25 และ EMA/DI ยังไปทางเดียวกัน) EA จะ Trailing SL ระยะ 1 ATR และ**เลื่อน TP3 ออกไปข้างหน้า**เรื่อย ๆ ให้กำไรวิ่งต่อได้ โดยไม้ยังมี TP อยู่ตลอด ถ้าเทรนด์เริ่มอ่อนจะหยุดเลื่อน TP และบีบ Trailing ให้แคบลง |
| **แก้ไม้ระหว่างถือ (Grid)** | ถ้าราคาวิ่งสวนเกิน 1 ATR และเทรนด์ M15 ยังไม่เสีย และมีแท่งเทียนยืนยัน จะเปิดไม้แก้เพิ่ม (ล็อต ×1.5 ต่อชั้น สูงสุด 3 ชั้น) แล้วตั้ง TP รวมทั้งตะกร้าไว้ที่ **จุดคุ้มทุนเฉลี่ย + 0.5 ATR** และ SL รวมของตะกร้าไว้ที่ 5 ATR จากไม้แรก |
| **แก้หลังแพ้ (After-loss)** | ถ้าตะกร้าล่าสุดปิดขาดทุน ไม้ถัดไปจะใช้ล็อต ×1.5 (สูงสุด 2 ขั้น) และกลับไปใช้ล็อตปกติเมื่อชนะ ค่านี้เก็บไว้ใน Global Variable จึงไม่หายตอนรีสตาร์ท MT5 |
| **คุมความเสี่ยง** | คำนวณล็อตจาก Risk % โดยรวมกรณีแย่สุดของไม้ Grid ทุกชั้นไว้แล้ว มีตัวกรองสเปรด เป้ากำไรต่อวัน (3%) ขาดทุนสูงสุดต่อวัน (5%) ตัดเมื่อ Drawdown ถึงที่กำหนด (15%) พักกี่แท่งหลังปิดตะกร้า กำหนดช่วงเวลาเทรดได้ และปิดออเดอร์วันศุกร์ |

## แดชบอร์ด

**แผงหลัก (ซ้าย)**
- การ์ด: Balance / Equity / Floating P/L และกำไร วันนี้ / สัปดาห์นี้ / เดือนนี้
- แถบความคืบหน้าเทียบกับเป้ากำไรรายวัน
- MARKET: เทรนด์ ADX RSI ATR สเปรด และสัญญาณล่าสุด
- POSITIONS: จำนวนไม้ ล็อต และกำไรของฝั่ง Buy/Sell, สถานะ (OPEN → TP1 + BE → RUNNER / RECOVERY), ชั้นแก้ไม้, ล็อตถัดไป, จำนวนครั้งที่แพ้ติดกัน, Win rate ของเดือน
- ปุ่มกด 18 ปุ่ม:

| | | |
|---|---|---|
| BUY | SELL | CLOSE ALL |
| CLOSE BUY | CLOSE SELL | BREAK-EVEN |
| CLOSE PROFIT | CLOSE LOSS | CLOSE 50% |
| AUTO: ON/OFF | RECOVERY: ON/OFF | RUNNER: ON/OFF |
| LOT − | (ล็อตสำหรับกดมือ) | LOT + |
| CALENDAR | UNLOCK DAY | REFRESH |

- ปุ่ม `-` / `+` ที่หัวแผงใช้ย่อหรือขยายแผง
- ป้ายสถานะ: AUTO ON / PAUSED / LOCKED / OFF HOURS

**ปฏิทินกำไร (ขวา)**
- ตารางรายเดือน แต่ละวันแสดงกำไร/ขาดทุนสุทธิ (รวมค่าคอมมิชชันและสว็อปแล้ว) และจำนวนไม้ที่ปิด วันที่กำไรเป็นสีเขียว วันที่ขาดทุนเป็นสีแดง วันนี้มีกรอบสีทอง
- ใช้ปุ่ม `<` `>` เลื่อนดูเดือนก่อนหน้า/ถัดไป และปุ่ม `TODAY` เพื่อกลับมาเดือนปัจจุบัน
- สรุปท้ายตาราง: กำไรทั้งเดือน, จำนวนวันเขียว, จำนวนวันแดง, วันที่กำไรสูงสุด
- ค่าเริ่มต้นนับเฉพาะออเดอร์ของ EA นี้ ถ้าต้องการรวมทั้งบัญชีให้ตั้ง `InpStatsAllTrades = true`

## วิธีติดตั้ง

1. ใน MT5 เปิดเมนู **File → Open Data Folder**
2. คัดลอก `QuantumScalper_M1.mq5` ไปไว้ที่ `MQL5/Experts/`
3. เปิด MetaEditor (F4) แล้วกด **Compile** (F7)
4. ลาก EA ไปวางบนกราฟ **M1** ของคู่เงินที่ต้องการ และเปิด **Algo Trading**
5. แนะนำให้ใช้บัญชีแบบ **Hedging** ถ้าเป็นบัญชี Netting EA จะเปิดไม้เดียวแล้วทยอยปิดบางส่วนที่ TP1/TP2 แทน และปิดโหมดแก้ไม้แบบ Grid

## พารามิเตอร์ที่ควรปรับ

| พารามิเตอร์ | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| `InpLotMode` / `InpRiskPercent` | Risk 1% | ความเสี่ยงกรณีแย่สุดของทั้งตะกร้า (รวมไม้ Grid ทุกชั้นแล้ว) |
| `InpMaxSpreadPts` / `InpMaxSpreadATRPct` | 0 (อัตโนมัติ) / 12% | 0 = ให้ EA คำนวณสเปรดสูงสุดจาก ATR เอง (ใช้ได้ทั้งทองและค่าเงิน) |
| `InpRecoveryMode` | Both | ตั้ง `Off` ได้ถ้าไม่ต้องการแก้ไม้ |
| `InpRecStepATR` × `InpRecMaxLevels` | 1.0 × 3 | ผลคูณต้องน้อยกว่า `InpRecBasketSL_ATR` (5.0) |
| `InpTP1_ATR` / `TP2` / `TP3` | 1 / 2 / 3.5 | ต้องเรียงจากน้อยไปมาก |
| `InpDailyTargetPct` / `InpDailyMaxLossPct` | 3% / 5% | เมื่อถึงเป้าจะหยุดเปิดไม้ใหม่ของวันนั้น |

## ⚠️ คำเตือนเรื่องความเสี่ยง

- การ**แก้ไม้แบบ Grid และการเพิ่มล็อตหลังแพ้** ช่วยให้ชนะบ่อยขึ้นก็จริง แต่ถ้าแพ้จะแพ้ไม้ใหญ่ EA ตั้งเพดานไว้แล้วหลายชั้น (จำกัดจำนวนชั้น, SL รวมของตะกร้า, ล็อตสูงสุด, ขาดทุนสูงสุดต่อวัน, Max DD) แต่ไม่มีระบบไหนรับประกันกำไรได้
- การเพิ่มล็อตหลังแพ้จะคูณความเสี่ยงต่อไม้เกิน Risk % ที่ตั้งไว้
- กราฟ M1 ไวต่อสเปรดและ Slippage ควรใช้บัญชีสเปรดต่ำ (ECN/Raw) และ VPS
- **ควร Backtest ใน Strategy Tester ด้วยโหมด "Every tick based on real ticks" และทดลองในบัญชี Demo อย่างน้อย 2–4 สัปดาห์** ก่อนใช้เงินจริง แต่ละคู่เงินควรใช้ค่า SL/TP/Recovery ไม่เหมือนกัน
